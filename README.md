# GOAT - Travel Agency Website

Un site web moderne d'agence de voyages avec système d'authentification et réservations.

## 🚀 Fonctionnalités

- **Authentification utilisateur** (Inscription/Connexion)
- **Galerie de destinations** avec navigation interactive
- **Système de réservation** avec recherche filtrée
- **Mode sombre/clair** avec persistance locale
- **Design responsive** (Mobile, Tablet, Desktop)
- **Profil utilisateur** personnalisable

## 📁 Structure du projet

```
GOAT/
├── goat.html          # Page principale
├── login.html         # Page de connexion
├── signup.html        # Page d'inscription  
├── profile.html       # Profil utilisateur
├── settings.html      # Paramètres
├── goat.css           # Styles principaux
├── goat.js            # Interactions principales
├── auth.js            # Authentification
├── assets/            # Images et ressources
└── README.md          # Documentation
```

## 🛠 Technologies utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Design moderne avec animations
- **JavaScript Vanilla** - Logique côté client
- **Font Awesome** - Icônes
- **Google Fonts** - Typographie Poppins

## 🎯 Points clés

- Stockage local pour les données utilisateur (localStorage)
- Navigation fluide avec scroll smooth
- Carrousel automatique des destinations
- Validation des formulaires côté client
- Interface responsive et accessible

## 📝 Notes de développement

- Le projet utilise uniquement JavaScript vanilla (pas de framework)
- Les données sont persistées localement dans le navigateur
- Le design suit les meilleures pratiques UX/UI modernes
- Le code est commenté en français pour maintenabilité

## 🌐 Déploiement

Ouvrir `goat.html` directement dans un navigateur web. Aucun serveur requis pour le développement.
